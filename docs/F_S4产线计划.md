# S4（31–40）耦合段产线计划

> 目标：把 GDD §7.2 里 31–40 的目标规格变成可入库关卡，**11-10 结束前冻结 S4**，11-11 留给 S5。
> 这一段不再问「消不消」，只问「先消谁」；加颜色/加墙/加尺寸只做布景，不做主杠杆。

---

## 1. 这一段要解决什么

S3 的问题是「哪些该消、哪些该留」；S4 的问题换成「同一张盘上，先解哪一对」。

- 目标回到**清空全场**（#38 除外，仍是清红）。
- 规模按 GDD：10–12 块 / 4–5 色 / 5–6 次消除 / 3–4 格内墙。
- 难度只来自**顺序耦合**：多对共用一条通道、一对给另一对当刹车、先清「钥匙」反而把门锁死。
- 每关只加**一种**新的耦合形态；同一形态不连续出现两次。

**总公式**：难度 ≈ 需要做的消除顺序决策数 × 错序的诱惑强度 × 错序后的补救步数。

## 3. 验收门槛（硬门槛，全部通过才入库）

| 代号 | 门槛 | 检查方式 |
|---|---|---|
| A | par 命中，且 `limit - par` 符合上表 | `s4_check --par/--limit` |
| B | 所有首步都能在上限内通关；死局 0（或明确记录扫描未完成） | `verify --dead --first` |
| C | 保持 par 的首步 2–8 个；至少一个首步被惩罚；开局现成对里至少一个不是最优 | `s4_check` |
| D | 整组墙拆掉后 par 必降；最优路径至少一次墙停；不要求每格墙单独有用 | `s4_check` |
| E1 | 清场关：每种颜色整色拿掉后 par 必降；至少两种颜色降 ≥2 步 | `s4_check` |
| E2 | 清色关：每种非目标色整色拿掉后 par 必变；目标色块数为偶数 | `s4_check` |
| F | 顺序压力 ≥1：最优路径上至少有一处「≥2 个可消对，且至少一个错选被惩罚」 | `s4_check` |
| G | 可读性：≤12 块、≤5 色、内墙 3–4 格；每关只加一种新耦合 | 人工 |
| H | 不允许「唯一首步才过」；保持 par 的首步至少 2 个 | `s4_check` |

> C 的 2–8 比 S3 的 1–5 宽：S4 块数到 12，等价首步自然变多；但**至少一个诱惑被惩罚**和 **F 顺序压力**不能放宽。

## 5. 锚点基线（已用 s4_check 复跑）

### #34 五色交错

```
#######
#A.D#B#
#.#C..#
#D....#
#C..EE#
#.BA.##
#######
```

- par 10 / 上限 12；10 块 / 5 色 / 3 墙；A* 1.9 万节点。
- 首步 20（保持 par 5，最差 12，超上限 0），开局现成对 2。
- 顺序压力 1 个点（第 3 步，2 个可消对，2 个错选被惩罚）。
- 整色载荷 A→8、B→7、C→9、D→8、E→9（全部承重；A/B/D 降 ≥2）。
- 拆整组墙→9；最优路径墙停 3 / 块停 2 / 消除 5。
- **判定：PASS**。墙单格不强（只有 `(5,5)` 单独有用），按整组口径验收。

## 6. 分批推进

### Batch A：31–33（4 色，par 7–8）

- 布局：`tri-*` + 一个 `quad-*`；颜色配比优先 `A2B2C2D4`（4+2+2+2）或 `A4B2C2D2`。
- 先每关搜 3 个候选，人工挑 1 个；不追求一次出 10 个。
- #31 先做「三对共用一条通道」；#32 做「交错缺口」；#33 做「钥匙锁门」。

### Batch B：34–37（五色开场 + 借位/三角/直路）

- #34 直接用 seed，先补测试与文档，再动 35–37。
- #35 重点是「连续借位」：最优路径至少 2 次块停 + 1 次墙停。
- #36 三角形：三对绑成循环，先清任一对都还能救，但会多 1 步。
- #37 第一次 12 块 / 5 色：先确认可读性，再谈 par。

### Batch C：38–40（红海 + 紧上限）

- #38 用 seed；视试玩反馈决定是否减少开局现成对。
- #39/#40 上限只比 par 多 2；若最差首步超过上限，优先加等价首步，而不是直接放宽上限。
- #40 要求至少两条等价最优线，避免「背答案」。

## 8. 风险与回退

1. **A\* 爆炸**：S4 盘面状态数比 S3 大；单盘 par 超过 90 万节点就换布局/换颜色配比，不靠 `S4_NODES` 抬到几百万硬解。
2. **「五色」变成读图题**：5 色只放在 34/37/39/40；31–33/35–36 保持 4 色。
3. **顺序耦合不够**：整色载荷全过但 F=0 的盘面直接淘汰；不要用「现成对多」冒充耦合。
4. **#38 现成对偏多**：若试玩反馈「开局白送」，挪一块红或改一格墙，保持 par 7 / 上限 9。
5. **39/40 上限收紧**：若最差首步 > 上限，先加等价首步；加不了再记录后放宽到 12，不静默改表。
6. **进度落后**：宁可 40 关全绿，不要 50 关里有卡死；底线不变。
