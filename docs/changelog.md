## 2026-11-12 · 评委视角最后一轮

依据官方答疑文档（玩法 50% / 关卡 30% / 迭代 20%；评委可能跳关；失败要能
说出原因；新机制先学后组合；鼠标也要顺手），本轮只修体验层，不改规则内核。
两批落地：上午按官方约束补呈现差距，下午复核修口径不一致。

### 新增

- **默认全关可选**：`UNLOCK_ALL` 默认开启，评委可直接从选关页进入任意一关；
  `?locked=1` 恢复逐关解锁。
- **失败诊断**：失败页显示还差几对、还差几个泊位；后台 Worker 从历史快照中
  找「最后还能赢的一步」，提供 `回到第 N 步（还有救）`。
- **新规则卡**：首次遇到钉子 / 泊位 / 最后一对 / 目标切换时弹一次，只讲当前
  机制；同一关有多条未讲规则时合并成一张「一次讲清」。
- **HUD 进度**：目标旁常驻「还差 N 对」与「泊位 x/y」；剩 1–2 步时优先提示步数。
- **鼠标悬停**：可拖方块 `grab` + 描边，钉子 `not-allowed`。
- **解法面板逐步走法**：面板改用 `src/solutions.js` 的坐标走法渲染逐步列表
  （含「停在第 X 行第 Y 列 / 撞上同色 / 撞掉钉子 / 停进泊位」）；`nudge` 叙述
  降为面板开头的「思路」引言。此前按 nudge 分号切分，长叙述关卡（如 #8）
  只渲染 1 条，无法照着走。
- **目标色反馈**：消掉非目标色时明确提示「不算目标」，读屏同步。
- **文档**：`docs/rules.md`、`docs/level-spec.md`、本文件。

### 调整

- `#40` 上限 11 → 12，`#45` 上限 11 → 12：首次引入「最后一对」/「泊位」时
  各多 1 步容错；`par` 与 `src/solutions.js` 不变。
- **HUD 星级行与结算同口径**：`updateHud()` 的星级行改为按
  `starsFor(level, moves, hintUsed)` 计算（先按步数定档，再减本次提示扣星，
  最低 1★）；用了提示后立即显示「2★ ≤ N 步 · 提示扣 1★」（琥珀）/
  「1★ · 上限 L 步 · 提示扣 2★」（红），点提示当场刷新。此前扣星后仍显示
  拿不到的「3★ ≤ N 步」，与结算页矛盾。
- 帮助页后期规则从常驻列表改为 `<details>` 折叠。
- `tools/test_rules.mjs` 同步 #40 上限断言。
