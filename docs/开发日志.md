## 2026-11-10：消除抖动减弱 + 分层提示（试玩反馈）

- **反馈**：① 消除时的震动「看着屏幕在晃」，观感不好；② 提示希望分层——第 1 次给小 tips，第 2 次更明显，第 3 次给完整解答，后两次各扣 1★。
- **抖动减弱**：`src/render.js` 里原来的轻震是 `sin(elapsed * 1.1) * cell * 0.08` / `cos(elapsed * 1.5) * cell * 0.06`，而 `elapsed` 是毫秒——每帧相位跳约 17 rad，等于随机噪点式抖动，峰值 0.08 格（60 px 格≈4.8 px），所以看起来是整屏在晃。改成 130 ms 窗口内的单周期衰减：`amp = cell * 0.022 * (1-k)^2`，`shakeX = sin(k·2π)·amp`、`shakeY = cos(k·2π)·amp·0.7`。探针逐帧记录 canvas `translate`：位移窗口 120 ms、峰值 0.873 px（0.0146 格），约为原来的 1/5.5；`prefers-reduced-motion` 下完全不位移（0 次 translate）。粒子、冲击环、停靠挤压、`navigator.vibrate(15)` 全部保留。
- **分层提示**：新增 `hintStep`（0 没点过 / 1 小 tips / 2 下一步 / 3 完整解法）、`hintPenalty()` / `addHintPenalty()` / `penaltyLine()` / `updateHintButton()` / `hintOverview()` / `showHintTier1()` / `showHintTier2()` / `requestHint()`。
  - 第 1 层：`hintOverview()` 只讲方向——「场上还剩几对 / 现在有几对能直接消 / 没有现成对时先找能停住的位置（墙、边界、异色块）」，并预告「再点一次会指出下一步（扣 1★）」，免费。

  - 第 3 层：直接打开原来的完整解法面板，再扣 1★；面板备注写「本关已用提示扣 N★，最高 M★」。第 4 次点击只是重新打开面板，不再扣分（上限 2★）。
  - 扣分存 `save.hintPenalty[关卡 id]`（0–2），按关永久累计；`loadLevel` 只把 `hintStep` 归零，已付的星不会重复扣。旧存档的 `save.assisted` 自动迁移成 `hintPenalty[id] = 1` 并删掉原字段；已得 `save.stars` 保留，不追溯降星。
