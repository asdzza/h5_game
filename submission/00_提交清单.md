## 3. 游戏本体 zip 结构

```text
03_游戏本体_撞个正着_v1.0.zip
├── index.html          ← 站点入口，位于 zip 根目录
├── styles.css
├── README.txt          ← 运行说明（含静态服务器启动方式）
└── src/
    ├── main.js
    ├── game.js
    ├── levels.js
    ├── render.js
    ├── input.js
    ├── solver.js
    ├── solutions.js
    ├── audio.js
    └── dead-worker.js
```

已校验：

- zip 共 **12 个条目**，`index.html` 位于**根目录**，没有多套一层文件夹。
- 解压后通过 `python -m http.server` 启动，页面正常显示标题页，关卡数为 **50**。
- 11-12 无头 Chrome 冒烟 13/13：标题页、默认全关可选、#45 泊位规则卡、HUD 泊位进度、鼠标悬停、非目标色反馈、失败诊断、一键回退、#50 补课、无未捕获异常。
- 11-12 复核冒烟（第二批）：#8 三层提示 HUD 星级行 3★ → 2★ → 1★ 逐层与结算口径一致；#8 / #50 解法面板按预置解法渲染逐步走法（泊位、钉子明确标注）；320px / 360px 无 HUD 裁切；零控制台错误。
- 不包含 `tools/`、`docs/`、`research/`、`node_modules/` 等开发文件。

> **运行注意**：本作使用原生 ES Module。受浏览器安全策略限制，**不要直接双击 `index.html`**（`file://` 下模块脚本会被 CORS 拦截）。请在该目录启动任意静态服务器，或上传到 HTTP(S) 托管后访问。README.txt 内已写明。

1. **游戏本体**：上传 `03_游戏本体_撞个正着_v1.0.zip`，确认平台解压后根目录能看到 `index.html`。

5. **迭代优化过程文档**：上传 `05_迭代优化过程文档.pdf`。
